# اصول

کتابخانه‌ای از الگوهای امتحان‌شده برای کارهای رایج با هوش مصنوعی — لحن رسانه‌ای/دانشگاهی، جدا از سایت اصلی، اما در آینده باهم ادغام می‌شوند.

## اضافه‌کردن یک الگوی جدید

داخل `index.html`، آرایه‌ی `TEMPLATES` را باز کن، یک آبجکت جدید مثل این اضافه کن:

```js
{
  title: 'اسم کار',
  intro: 'یک جمله درباره‌ی چالش رایج این کار',
  prompt: 'متن کامل الگو/پرامپت',
  why: 'چرا این روش تلاش هدررفته را کم می‌کند'
}
```

ذخیره کن، بعد در همین پوشه بزن: `bash publish.sh usul`
